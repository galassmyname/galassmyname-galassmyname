# Serigne Fallou Mbaye

**Junior software engineer — full stack & backend, growing into AI/ML.**

I build web applications end to end: REST APIs, real-time features, admin dashboards and the Docker/Kubernetes setup to run them. I studied Systems, Networks & Telecommunications, I study Information Systems at Université Alioune Diop de Bambey (UADB), and since July 2026 I have been following the intensive **P1 Artificial Intelligence** program at Sonatel Academy.

I like problems with a local, practical impact, such as tracking city buses in real time, managing food deliveries in Keur Massar, or building a French–Wolof dictionary.
